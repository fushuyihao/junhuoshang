# 军火商 (Arms Dealer)

倒卖子弹记录与跨设备同步工具。

## 功能
- 📦 仓库：记录采购（名称/数量/单价/时间），自动算回本价（单价×1.156），同款合并为均价行。
- 💰 价格表：记录子弹价格与时刻，显示历史最低价，含每日均价/日内波动折线图。
- 📈 销售：记录卖出，自动算单颗利润与利润率，显示近 7 天统计。

## 运行
```bash
node server.js          # 启动后端（端口 3000），同时托管前端 public/
```

## 部署
零依赖 Node 应用，可直接部署到 Render / Fly.io 等平台（见 render.yaml）。
